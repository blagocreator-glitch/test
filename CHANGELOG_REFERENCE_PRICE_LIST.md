# Изменения: Эталонный прайс-лист работ

## Дата: 2024

## Суть изменений

Все работы из прайс-листа теперь являются **эталонными**. Это означает, что `prices_list.json` — единственный источник истины для всех работ в системе.

## Что изменилось

### 1. Добавлены комментарии в код

**Файл:** `prices_list.js`

Добавлен комментарий в начале файла:
```javascript
// ВАЖНО: Все работы в прайс-листе являются ЭТАЛОННЫМИ.
// Это означает, что prices_list.json - единственный источник истины для:
// - Названий работ
// - ID работ
// - Единиц измерения
// - Базовых цен по городам и сегментам
// Любые изменения в составе работ должны вноситься только в prices_list.json
```

### 2. Добавлена функция валидации

**Файл:** `prices_list.js`

Новая функция `validateWorkIdsAgainstPriceList(workIds)`:
- Проверяет, что все используемые workId есть в прайс-листе
- Выводит предупреждения в консоль, если найдены невалидные работы
- Доступна глобально через `window.validateWorkIdsAgainstPriceList`

### 3. Автоматическая валидация при загрузке

**Файл:** `prices_list.js`, функция `initPriceList()`

При инициализации прайс-листа автоматически:
- Собираются все workId из `roomData.demolitionData` и `roomData.repairData`
- Проверяется их наличие в эталонном прайс-листе
- Выводится результат в консоль:
  - ✅ Если все работы найдены
  - ⚠️ Если есть работы, которых нет в прайс-листе

### 4. Обновлена документация

**Новые файлы:**
- `REFERENCE_PRICE_LIST.md` — подробное руководство по работе с эталонным прайс-листом
- `PRICE_LIST_CHEATSHEET.md` — краткая памятка для разработчиков

**Обновлённые файлы:**
- `README.md` — добавлен раздел об эталонном прайс-листе
- `PRICE_LIST_README.md` — добавлен раздел "ВАЖНО: Эталонный источник данных"

## Как это использовать

### Для разработчиков

1. **Всегда используйте функции из `prices_list.js`:**
   ```javascript
   const price = getWorkPrice('floor_laminate');
   const workId = findWorkIdInBranch(branch, 'Ламинат');
   ```

2. **Никогда не хардкодьте работы в коде:**
   ```javascript
   // ❌ Неправильно
   const work = { name: 'Ламинат', unit: 'м²', price: 500 };
   
   // ✅ Правильно
   const workId = 'floor_laminate';
   const price = getWorkPrice(workId);
   ```

3. **Проверяйте консоль при разработке:**
   - Открывайте DevTools → Console
   - Ищите сообщения о валидации работ
   - Исправляйте найденные проблемы

### Для добавления новых работ

1. Открыть `prices_list.json`
2. Добавить работу в нужную категорию
3. Добавить цены для всех городов и сегментов
4. Перезагрузить страницу и проверить консоль

## Преимущества

✅ **Единый источник истины** — нет дублирования данных
✅ **Автоматическая валидация** — ошибки обнаруживаются сразу
✅ **Простота обновления** — изменения в одном месте
✅ **Консистентность** — все работы используют одинаковые названия и единицы
✅ **Масштабируемость** — легко добавлять новые города и сегменты

## Миграция существующего кода

Если в коде есть хардкод работ, нужно:

1. Найти все места с хардкодом
2. Заменить на использование функций из `prices_list.js`
3. Убедиться, что все работы есть в `prices_list.json`
4. Проверить консоль на наличие ошибок валидации
