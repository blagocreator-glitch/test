## 🆘 Быстрое решение проблем

### Проблема: Не отправляется почта
1. Проверить `.env` (SMTP-настройки)
2. Проверить `logs/mail_debug.log`
3. Проверить rate limiting (файлы в `logs/rate_limit_*.txt`)
4. Проверить SMTP-сервер (telnet test)

### Проблема: Не работает калькулятор
1. Открыть консоль браузера (F12)
2. Проверить загрузку `prices_list.json`
3. Проверить порядок подключения скриптов в `index.html`
4. Проверить валидацию workId в консоли

### Проблема: Ошибки в консоли
1. Проверить, что все JS-файлы загружаются
2. Проверить порядок подключения (см. ARCHITECTURE.md)
3. Проверить синтаксис JS-файлов (`node -c`)
4. Очистить кеш браузера

### Проблема: Медленная загрузка
1. Проверить размеры изображений
2. Проверить Network tab в DevTools
3. Включить Gzip на сервере
4. Рассмотреть CDN для статики
