## 📅 Дорожная карта

### Фаза 1: Стабилизация (1-2 недели)

#### Неделя 1: Безопасность и защита
**Цель:** Защитить сайт от ботов и спама

**Задачи:**
1. **Добавить reCAPTCHA v3** (Приоритет: 🔴 Высокий)
   - Зарегистрироваться на https://www.google.com/recaptcha
   - Получить ключи (site key и secret key)
   - Добавить скрипт в `index.html`
   - Обновить `send-mail.php` для проверки токена
   - Протестировать на разных устройствах
   
   **Время:** 2-4 часа  
   **Файлы:** `index.html`, `send-mail.php`

2. **Настроить мониторинг ошибок** (Приоритет: 🟡 Средний)
   - Интегрировать Sentry или аналог
   - Настроить алерты на email/Telegram
   - Добавить логирование критических ошибок
   
   **Время:** 2-3 часа  
   **Файлы:** `send-mail.php`, новый `error-handler.php`

#### Неделя 2: Документация и тестирование
**Цель:** Улучшить документацию и начать тестирование

**Задачи:**
1. **Документировать API** (Приоритет: 🟡 Средний)
   - Создать `API.md`
   - Описать endpoint `send-mail.php`
   - Документировать параметры запроса
   - Описать форматы ответов
   - Добавить примеры использования
   
   **Время:** 2-3 часа  
   **Файлы:** новый `API.md`

2. **Провести ручное тестирование** (Приоритет: 🔴 Высокий)
   - Протестировать все формы
   - Проверить калькулятор на разных сценариях
   - Тестировать на мобильных устройствах
   - Проверить отправку почты
   - Документировать найденные баги
   
   **Время:** 4-6 часов  
   **Файлы:** новый `TESTING.md`

### Фаза 2: Оптимизация (2-4 недели)

#### Неделя 3-4: Производительность
**Цель:** Ускорить загрузку и работу сайта

**Задачи:**
1. **Оптимизировать изображения** (Приоритет: 🟡 Средний)
   - Конвертировать в WebP
   - Создать разные размеры (responsive images)
   - Добавить lazy loading для всех изображений
   - Сжать PNG/JPG
   
   **Время:** 3-4 часа  
   **Инструменты:** ImageMagick, Squoosh, TinyPNG

2. **Self-host Tailwind CSS** (Приоритет: 🟢 Низкий)
   - Скачать Tailwind CSS
   - Настроить purge для удаления неиспользуемых стилей
   - Минифицировать CSS
   - Обновить `index.html`
   
   **Время:** 2-3 часа  
   **Файлы:** `index.html`, новый `tailwind.config.js`

3. **Минифицировать JavaScript** (Приоритет: 🟢 Низкий)
   - Настроить Terser или UglifyJS
   - Создать минифицированные версии всех JS-файлов
   - Обновить `index.html` для использования .min.js
   - Настроить source maps для отладки
   
   **Время:** 2-3 часа  
   **Инструменты:** Terser, webpack/Vite

#### Неделя 5-6: Автоматизация
**Цель:** Настроить автоматическое тестирование

**Задачи:**
1. **Написать unit-тесты** (Приоритет: 🟡 Средний)
   - Установить Jest
   - Написать тесты для calc-utils.js
   - Написать тесты для calc-pricing.js
   - Написать тесты для demolition.js
   - Настроить coverage reporting
   
   **Время:** 8-12 часов  
   **Файлы:** новая папка `tests/`, `package.json`

2. **Настроить CI/CD** (Приоритет: 🟢 Низкий)
   - Создать GitHub Actions workflow
   - Автоматический запуск тестов при push
   - Автоматическая валидация JSON
   - Автоматическая проверка синтаксиса
   
   **Время:** 2-4 часа  
   **Файлы:** `.github/workflows/ci.yml`

## 🛠️ Быстрые победы (Quick Wins)

Задачи, которые можно сделать быстро и получить заметный эффект:

### 1. Добавить favicon (15 минут)
```html
<link rel="icon" type="image/png" href="favicon.png">
```

### 2. Добавить Open Graph метатеги (30 минут)
```html
<meta property="og:title" content="Ваши Мастера - Ремонт квартир">
<meta property="og:description" content="Профессиональный ремонт квартир">
<meta property="og:image" content="https://вашимастера.рус/og-image.jpg">
```

### 3. Добавить structured data (Schema.org) (1 час)
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Ваши Мастера"
}
```

### 4. Включить Gzip сжатие (15 минут)
```apache
# .htaccess
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css text/javascript
</IfModule>
```

### 5. Добавить robots.txt (10 минут)
```
User-agent: *
Allow: /
Sitemap: https://вашимастера.рус/sitemap.xml
```
