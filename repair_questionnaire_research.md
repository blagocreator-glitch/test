# Исследование и предложения по улучшению опросника ремонта

## Что есть сейчас

### Примерный расчет
- По комнате спрашиваются:
  - текущее состояние помещения;
  - что демонтировать, если есть старая отделка;
  - желаемая отделка пола, стен и потолка;
  - укрупненный пакет инженерии;
  - менять ли электрику, сантехнику, отопление;
  - нужен ли интернет/ТВ, кондиционер, smart home, защита;
  - блок "комфорт": свет, шторы, декор, теплый пол, гидроизоляция, шумоизоляция, замена дверей/окон/балконного блока.

### Полный расчет
- Отличается главным образом тем, что в инженерии можно указать количества:
  - розетки, выключатели, светильники;
  - интернет-точки;
  - водоточки, канализационные точки, радиаторы.
- Для кухни и санузла есть отдельные специальные блоки.

## Главные выводы

### 1. Часть важных данных уже есть, но пользователь этого не видит
- Двери, окна и их размеры уже собираются в разделе помещений.
- В квесте про них спрашивается только "меняем / не меняем".
- Из-за этого создается ощущение, что вопрос "про окна и двери" вообще не задали.

### 2. Нет нескольких вопросов с очень высоким влиянием на смету
- Что именно нужно получить на выходе:
  - черновая;
  - white-box;
  - чистовая;
  - под ключ.
- Масштаб замены инженерии:
  - локально добавить точки;
  - частично заменить;
  - полностью заменить.
- Нужны ли работы по проемам:
  - просто замена полотна/окна;
  - замена с откосами;
  - расширение / перенос / усиление.

### 3. Полный расчет сейчас "подробнее", но не всегда "точнее"
- Он добавляет счетчики по инженерии, но мало уточняет сценарий использования комнаты.
- Для точной сметы часто важнее не просто количество точек, а контекст:
  - будет ли ТВ-зона;
  - рабочее место;
  - кровать с прикроватными сценариями;
  - стиральная/сушильная машина;
  - скрытая сантехника;
  - двери обычные или скрытые;
  - окна с откосами, подоконниками, откосными узлами.

### 4. Опрос уже довольно длинный, поэтому добавлять вопросы "в лоб" опасно
- Улучшать нужно не через большое число новых обязательных вопросов.
- Нужен адаптивный сценарий: сначала короткий вопрос, затем 1-2 уточнения только если это действительно влияет на расчет.

## Что стоит улучшить

## 1. Добавить отдельный блок "Проемы: двери и окна"

### Для примерного расчета
- Показывать уже собранные данные:
  - дверей: N;
  - окон: N;
  - балконных блоков: N.
- Спросить коротко:
  - оставляем;
  - меняем стандартно;
  - меняем с доработкой проема.

### Для полного расчета
- Если выбрано "меняем", показывать 2-3 уточнения:
  - тип двери: обычная / скрытая;
  - для окон: только замена / замена с откосами и подоконниками;
  - нужен ли демонтаж старых конструкций;
  - есть ли расширение или перенос проема.

### Почему это важно
- Это закрывает пользовательское ощущение "не спросили про окна и двери".
- Это дает смете сильный ценовой сигнал без перегруза.

## 2. Явно спрашивать итоговый формат ремонта

### Сейчас
- В данных комнаты это поле существует, но в самом квесте почти не чувствуется.

### Стоит сделать
- В начале квеста по комнате спросить:
  - черновая;
  - white-box;
  - чистовая;
  - под ключ.

### Почему это важно
- Это один из самых сильных факторов стоимости.
- Без этого часть логики выглядит "слишком автоматически" и может не совпасть с ожиданием клиента.

## 3. Разделить "замену инженерии" на 3 уровня вместо Да/Нет

### Вместо
- Меняем электрику? Да / Нет
- Меняем сантехнику? Да / Нет
- Меняем отопление? Да / Нет

### Лучше
- не трогаем;
- частично;
- полностью.

### Почему это важно
- Да/Нет слишком грубо.
- Многие реальные объекты попадают в "частично":
  - добавить розетки без полной замены;
  - перенести несколько сантехточек;
  - заменить 1 радиатор.

## 4. Для примерного расчета добавить 3-4 вопроса с максимальной пользой

### Рекомендуемый состав
- Итог ремонта:
  - white-box / чистовая / под ключ.
- Масштаб инженерии:
  - минимально / частично / полностью.
- Проемы:
  - ничего не меняем / меняем стандартно / меняем с доработкой.
- Наполнение комнаты:
  - базовое / комфорт / насыщенное.

### Для отдельных помещений
- Санузел:
  - ванна / душевая;
  - стиральная машина: да / нет.
- Кухня:
  - газ / электро;
  - посудомойка: да / нет;
  - обычная / насыщенная техникой.

### Этого достаточно
- Примерный сценарий останется быстрым.
- Но точность заметно вырастет.

## 5. Для полного расчета добавить не больше 1-2 уточнений на тип комнаты

### Жилая комната
- будет ТВ-зона: да / нет;
- будет рабочее место: да / нет.

### Спальня
- нужны прикроватные сценарии: да / нет;
- будет кондиционер: нет / подготовка / монтаж.

### Детская / кабинет
- базовая электрика / насыщенная электрика.

### Санузел
- стиральная машина: да / нет;
- скрытые смесители: да / нет;
- душевой трап / ванна.

### Кухня
- духовой шкаф отдельно: да / нет;
- вытяжка: базовая / встроенная;
- фильтр / измельчитель / доп. техника: да / нет.

### Прихожая
- видеодомофон: да / нет;
- теплый пол: да / нет;
- встроенный шкаф с подсветкой: да / нет.

## 6. Перенести некоторые вопросы в более логичные блоки

### Сейчас не очень логично
- двери и окна находятся в блоке "Комфорт, детали и стиль".

### Лучше
- выделить:
  - "Исходное состояние";
  - "Что нужно демонтировать";
  - "Проемы: двери и окна";
  - "Инженерия";
  - "Чистовая отделка и комфорт".

### Почему это важно
- Пользователю проще мыслить этапами ремонта, а не внутренней структурой калькулятора.

## 7. Показывать "что уже известно" и спрашивать только про изменения

### Пример
- Уже знаем:
  - 2 двери;
  - 1 окно;
  - площадь 18.4 м².
- Уточните только:
  - оставляем или меняем;
  - стандартная замена или сложный узел.

### Эффект
- Вопросов визуально меньше.
- Пользователь видит, что система уже помнит данные и не заставляет вводить их заново.

## Предлагаемая структура опросника

## Примерный расчет
1. Что есть сейчас?
2. Что хотим получить?
3. Насколько глубоко трогаем инженерию?
4. Что делаем с дверями / окнами?
5. Нужны ли особые решения для этой комнаты?

### Особые решения по типу комнаты
- Санузел: ванна/душ, стиральная машина.
- Кухня: газ/электро, посудомойка, много техники или стандартно.
- Жилая: ТВ-зона, кондиционер, базовый или насыщенный свет.

## Полный расчет
1. Исходное состояние.
2. Демонтаж.
3. Итоговый формат ремонта.
4. Проемы.
5. Инженерия по количествам.
6. Спецблок комнаты.
7. Комфорт и декоративные решения.

## Чтобы форма не стала сложной

### Принципы
- Не добавлять все вопросы всем подряд.
- Показывать уточнения только после выбора значимого варианта.
- Использовать короткие варианты ответа вместо свободного текста.
- Держать лимит:
  - примерный расчет: 6-9 ключевых ответов на комнату;
  - полный расчет: 10-14 ответов на комнату, но с условным раскрытием.

### Что лучше не делать
- Не спрашивать размеры повторно, если они уже есть в "Помещениях".
- Не просить пользователя считать метры кабеля, труб или откосов.
- Не давать профессиональные термины без простого перевода на бытовой язык.

## Приоритет внедрения

### Быстрые улучшения
1. Добавить в квест отдельный блок по дверям/окнам с показом уже известных данных.
2. Добавить вопрос про итоговый формат ремонта.
3. Заменить Да/Нет по инженерии на "не трогаем / частично / полностью".

### Следующий этап
1. Добавить по 1-2 уточнения для кухни, санузла, жилой комнаты и прихожей.
2. Перестроить порядок блоков так, чтобы проемы были рядом с демонтажем.

### Позже
1. Сделать адаптивную детализацию для полного сценария.
2. Показывать "это повлияет на смету сильно / умеренно" для некоторых выборов.

## Итог

Лучшее направление не в том, чтобы "сильно удлинить" опросник, а в том, чтобы:
- вынести высоковлияющие вопросы наверх;
- показать уже известные данные;
- сделать отдельный короткий блок по проемам;
- заменить грубые Да/Нет на более реалистичные уровни;
- добавлять уточнения только там, где они действительно влияют на смету.

В таком виде и примерный, и полный расчет станут заметно точнее, но форма останется понятной и быстрой.
