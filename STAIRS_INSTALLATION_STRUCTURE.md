## Как это будет отображаться

После добавления этой структуры в `prices_list.json`, в разделе "Что нужно сделать" → "Монтажные работы по ремонту" появится:

1. **Лестницы и перила** (раскрывающаяся группа)
   - Монтаж деревянной лестницы
   - Монтаж металлической лестницы
   - Монтаж железобетонной лестницы
   - Монтаж ступеней лестницы
   - Облицовка лестницы
   - Монтаж балясин
   - Монтаж стоек лестницы
   - Монтаж деревянных перил
   - Монтаж металлических перил
   - Монтаж стеклянных перил
   - Монтаж поручня
   - Монтаж стоек перил

2. **Монтаж проемов** (раскрывающаяся группа)
   - Устройство дверного проема
   - Устройство оконного проема

Каждая работа будет отображаться с:
- Чекбоксом для выбора
- Названием работы
- Диапазоном цен (мин - макс)
- Единицей измерения
- Кнопками +/- для изменения количества
- Полем ввода количества
