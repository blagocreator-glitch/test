# Project Working Notes

- После каждого крупного завершенного блока изменений выполнять короткую проверку, затем делать понятный `git commit` и `git push` в GitHub-репозиторий.
- Не смешивать в одном коммите несвязанные изменения: если рабочее дерево уже содержит чужие или более ранние правки, сначала отделить текущую задачу.
- Перед отправкой на GitHub сообщать, какие проверки прошли и что вошло в коммит.
- Все пользовательские интерфейсы и доработки делать в стильном, премиальном виде: аккуратная визуальная иерархия, дорогая подача, удобные состояния и отсутствие перегруза.
- Каждую визуальную доработку сразу адаптировать под мобильную версию, чтобы сценарий был удобен и на десктопе, и на телефоне.
