- Проверить, что нет ошибок JavaScript

### 4. Тестирование монтажных работ

#### Черновые работы
1. Перейти в раздел "Что нужно сделать"

## 🐛 Известные проблемы

### Кодировка в консоли PowerShell
При просмотре файла через PowerShell кириллические символы могут отображаться некорректно (например, `¬?` вместо `м²`). Это нормально - в файле они хранятся как Unicode escape-последовательности (`\u043c\u00b2`), которые браузер корректно интерпретирует.

### Fallback на старые массивы
Если прайс-лист не загружен или работа не найдена, система автоматически использует старые массивы опций. Это нормальное поведение для обеспечения обратной совместимости.

## 📝 Что делать при ошибках

### Ошибка: "pricesData is not defined"
- Проверить, что файл `prices_list.json` загружается
- Проверить путь к файлу в `prices_list.js`

### Ошибка: "getInstallationWorkName is not defined"
- Проверить, что `installation.js` подключен в `index.html`
- Проверить порядок подключения скриптов

### Ошибка: "Cannot read property 'works' of undefined"
- Прайс-лист еще не загрузился
- Подождать полной загрузки страницы
- Проверить консоль на ошибки загрузки JSON
