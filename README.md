# Сайт для работы

Это PHP-проект для сайта простой витрины/форм отправки почты. В проекте присутствуют:
- index.html — основная страница
- send-mail.php — скрипт отправки письма через PHPMailer
- phpmailer/ — библиотека PHPMailer
- public_html/ — корень веб-контента
- logs/ — журналы ошибок/активности

Цели:
- обеспечить базовую отправку почты через PHPMailer
- дать краткое руководство по разворачиванию локально

Как запустить локально (пример для Windows):
- Установить PHP и добавить в PATH
- Открыть командную строку и перейти в этот каталог
- Перейти в каталог public_html и запустить встроенный сервер:
  php -S localhost:8000 -t ..

Дальнейшие шаги можно обсудить и оформить в виде задач (PRs) при необходимости.

## Текущая структура фронтенда (JS)

Крупный код из `index.html` вынесен в отдельные файлы. Это снижает вес HTML и упрощает поддержку.

Порядок подключения в `index.html` важен, так как файлы используют глобальные функции друг друга:

- `simple-calc.js` — логика простого калькулятора.
- `ui-core.js` — общие UI-обработчики (модалки, меню, навигация, формы).
- `calc-core.js` — базовое состояние калькулятора и общие расчетные данные.
- `calc-utils.js` — утилиты и вспомогательные функции для секций калькулятора.
- `demolition.js` — логика демонтажных работ.
- `calc-init.js` — инициализация детализированного калькулятора и базовые рендеры секций.
- `calc-render.js` — рендер блоков помещений и связанных полей.
- `calc-repair-quest.js` — квест-опрос по ремонту и его аудит.
- `calc-building.js` — логика выбора типа/подтипа/материала здания.
- `calc-ui-toggles.js` — UI-переключатели опций в форме сметы.
- `calc-address.js` — автоподсказки и выбор адреса.
- `calc-room-ui.js` — расширенный UI управления комнатами.
- `calc-summary-render.js` — рендер блоков работ/материалов/допуслуг и промежуточных итогов.
- `calc-pricing.js` — выбор позиций, цены, пересчет итогов.
- `calc-flow.js` — оставшаяся связующая логика сценариев калькулятора.
- `app-init.js` — инициализация пространства имен `App`.
- `prices_list.js` — логика прайс-листа (⚠️ **ЭТАЛОННЫЙ источник всех работ**).

### ⚠️ Важно: Эталонный прайс-лист

**Все работы в системе калькулятора должны быть определены только в `prices_list.json`.**

Это единственный источник истины для:
- Названий работ
- ID работ
- Единиц измерения
- Базовых цен по городам и сегментам

### Рекомендации для дальнейшего рефакторинга

- Сохранять обратную совместимость: сначала переносить код 1-в-1, потом улучшать.
- Не менять порядок подключения скриптов без проверки зависимостей.
- Новые функции добавлять в тематический модуль, а не обратно в `index.html`.
