Формат ID комнаты: demo_living_0, demo_living_1, ... (для жилых)

HTML комнаты (строка ~5128):
- div с id="${roomId}Room" (например: demo_living_0Room)

=================================================================
СЕКЦИИ ВНУТРИ КОМНАТЫ
=================================================================

Каждая комната содержит 3 секции:

1. Демонтаж внутренних конструкций (строка ~5139):
   - ID заголовка: ${roomId}_constructHeader
   - ID контента: ${roomId}_constructContent
   - Иконка галки: ${roomId}_constructDone
   - Внутри содержит:
     * Демонтаж перегородок (partitionsSection)
       - ID section: ${roomId}_partitionsSection
       - ID заголовка: ${roomId}_partitionsHeader
       - ID контента: ${roomId}_partitionsContent
       - Количество (qty), список перегородок
     * Демонтаж проёмов (openingsSection)
       - ID section: ${roomId}_openingsSection
       - Внутри: дверной/оконный/балконный проем

2. Демонтаж инженерных систем (строка ~5160):
   - ID: ${roomId}_engineeringHeader
   - Контент: ${roomId}_engineeringContent
   - Внутри: электрика, водоснабжение, канализация, сантехника, отопление

3. Демонтаж отделочных материалов (строка ~5190):
   - ID: ${roomId}_finishingHeader
   - Контент: ${roomId}_finishingContent
   - Внутри три подраз��ела:
     * Снятие напольных покрытий (floor)
     * Удаление стеновых покрытий (wall)
     * Демонтаж потолочных конструкций (ceiling)

=================================================================
ФУНКЦИИ JAVASCRIPT
=================================================================

 toggleWhatToDoSubSection(id):
   - Переключает видимость контента (display: none/block)
   - Поворачивает иконку chevron
   - Сохраняет состояние в openWhatToDoSubSections Set
   - Вызывает checkDemolitionDone() для измененных подсекций

 updatePartitionCount(roomId, delta):
   - Изменяет количество перегородок (+/-)
   - Вызывает renderPartitionFields()
   - Вызывает checkDemolitionDone(roomId, 'partitions')
   - Вызывает checkDemolitionDone(roomId, '_construct')

 renderPartitionFields(roomId, count):
   - Рендерит поля для перегородок
   - Для каждой: материал, площадь, опционально демонтируемая площадь

 updatePartitionData(roomId, index, field, value):
   - Сохраняет данные в roomData.demolitionData[roomId].partitions[index]
   - Вызывает checkDemolitionDone(roomId, 'partitions')
   - Вызывает checkDemolitionDone(roomId, '_construct')

 handlePartitionInput(roomId):
   - Обрабатывает ввод количества
   - При 0 очищает данные partitions
   - Вызывает checkDemolitionDone()

 checkDemolitionDone(roomId, subType):
   - Проверяет заполненность данных
   - subType: 'partitions', '_construct', 'finishing', 'electrical', 'water' и т.д.
   - Показывает/скрывает галку (check icon)
   - Добавляет/убирает зеленую рамку (border-green-500)

Логика отображения галки:
   - ПОКАЗЫВАТЬ: 'finishing', '_construct'
   - НЕ ПОКАЗЫВАТЬ: 'partitions', 'finishing_floor', 'finishing_wall', 'finishing_ceiling'

Логика зеленой рамки (border-green-500):
   - ДЛЯ: 'partitions' -> ${roomId}_partitionsSection
   - 'finishing_floor/wall/ceiling' -> ${roomId}_finishing_floor/wall/ceilingHeader
   - '_construct' -> ${roomId}_constructHeader
