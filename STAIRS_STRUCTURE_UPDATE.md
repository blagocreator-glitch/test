# Новая структура лестниц в калькуляторе

**Дата:** 2026-05-06  
**Статус:** ✅ РЕАЛИЗОВАНО

---

## 📋 Обзор изменений

Раздел "Лестницы и перила" в калькуляторе ("Что нужно сделать") был полностью переработан для соответствия структуре прайс-листа.

### До изменений ❌
- Простой счётчик количества лестниц
- Нет детализации по типам работ
- Нет выбора материалов
- Нет подкатегорий

### После изменений ✅
- Полная иерархическая структура как в прайс-листе
- 3 основные категории: Монтаж, Облицовка, Перила
- Множественные подкатегории по материалам и типам
- Выбор конкретных работ из прайс-листа
- Указание количества для каждой работы

---

## 🏗️ Структура категорий

### 1. Монтаж лестниц (stair_install)

#### 1.1 По материалу (by_material)
- **Бетон** (concrete) — 12 работ
- **Металл / металлокаркас** (metal) — 12 работ
- **Дерево** (wood) — 12 работ
- **Камень** (stone) — 9 работ
- **ДПК / композит** (composite) — 7 работ

#### 1.2 Типовая лестница (standard_size)
- 14 работ (стандартные размеры)

#### 1.3 Увеличенная лестница (increased_size)
- 14 работ (увеличенные размеры)

#### 1.4 Винтовая лестница (spiral)
- 6 работ

#### 1.5 Индивидуальный проект (custom)
- 18 работ

#### 1.6 Поэлементный монтаж (element)
- 13 работ

### 2. Облицовка лестниц (stair_cladding)

- **Керамогранит / керамика** (porcelain) — 9 работ
- **Натуральный камень** (natural_stone) — 4 работы
- **Дерево / массив** (wood) — 6 работ
- **Металл** (metal) — 2 работы
- **ДПК / композит** (composite) — 3 работы

### 3. Монтаж перил (railing_install)

- **Дерево** (wood) — 6 работ
- **Металл** (metal) — 8 работ
- **Стекло** (glass) — 4 работы
- **Ковка** (forged) — 3 работы
- **ДПК / ПВХ** (composite) — 3 работы

## 💻 Техническая реализация

### Новые файлы

#### calc-stairs.js
Новый модуль для работы с лестницами:
- `renderStairsFields()` — рендер всех полей лестниц
- `renderStairsItem()` — рендер одного элемента лестницы
- `addStairsItem()` — добавление новой лестницы
- `removeStairsItem()` — удаление лестницы
- `updateStairsMainCategory()` — обновление основной категории
- `updateStairsSubCategory()` — обновление подкатегории
- `updateStairsWork()` — обновление выбранной работы
- `updateStairsQty()` — обновление количества
- `getStairsOptionsFromPriceList()` — получение опций из прайс-листа

### Изменённые файлы

#### calc-init.js
- Добавлена специальная обработка для `category === 'stairs'` в `renderRepairCategoryFields()`
- Добавлена проверка в `updateRepairItem()` для пропуска лестниц

#### index.html
- Добавлено подключение `<script src="calc-stairs.js"></script>` перед `calc-init.js`

## 🎨 Пользовательский интерфейс

### Добавление лестницы

1. Нажать кнопку "+ Добавить"
2. Выбрать категорию работ (Монтаж / Облицовка / Перила)
3. Выбрать тип / материал из выпадающего списка
4. Выбрать конкретную работу
5. Указать количество

### Редактирование лестницы

- Изменение категории сбрасывает все зависимые поля
- Изменение типа/материала обновляет список доступных работ
- Выбор работы автоматически подставляет единицу измерения

### Удаление лестницы

- Кнопка "×" в правом верхнем углу карточки лестницы

## 🔄 Интеграция с прайс-листом

### Получение опций

Функция `getStairsOptionsFromPriceList()` динамически получает список работ из `prices_list.json`:

```javascript
const options = getStairsOptionsFromPriceList(
  'stair_install',    // mainCategory
  'by_material',      // subCategory
  'concrete'          // subSubCategory
);

// Возвращает:
[
  {
    value: 'finish_stair_mat_stair_install_concrete_straight_h3_w11',
    label: 'Монтаж бетонной прямой лестницы h=3м, w=1.1м',
    unit: 'шт'
  },
  // ...
]
```

### Навигация по структуре

Модуль автоматически навигирует по иерархии прайс-листа:
```
pricesData.works.installation.categories.finishing.subcategories.stairs
  └─ subcategories[mainCategory]
      └─ subcategories[subCategory]
          └─ subcategories[subSubCategory]
              └─ items[]
```

## ✅ Преимущества новой структуры

### 1. Соответствие прайс-листу ✅
Полное соответствие структуре из `prices_list.json`

### 2. Детализация ✅
- Выбор конкретных работ вместо общего "лестница"
- Разделение по материалам и типам
- Точное указание количества

### 3. Гибкость ✅
- Можно добавить несколько разных работ для одной лестницы
- Например: монтаж + облицовка + перила

### 4. Автоматическое обновление ✅
- При изменении прайс-листа автоматически обновляются опции
- Не нужно менять код калькулятора

### 5. Корректный расчёт ✅
- Используются актуальные ID работ с префиксами
- Правильные единицы измерения из прайс-листа
- Точный расчёт стоимости

## ⚠️ Важные замечания

1. **Порядок загрузки:**
   - `prices_list.js` должен загрузиться первым
   - `calc-stairs.js` должен загрузиться до `calc-init.js`

2. **Зависимости:**
   - Требуется `window.pricesData` (из prices_list.js)
   - Требуется `roomData` (из calc-init.js)

3. **Обратная совместимость:**
   - Старые данные с простым счётчиком не поддерживаются
   - При первом открытии нужно заново добавить лестницы
