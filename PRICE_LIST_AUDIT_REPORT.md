## 🔧 Рекомендации по исправлению

### Вариант 1: Добавить префиксы (РЕКОМЕНДУЕТСЯ)

Добавить префиксы к ID для разделения демонтажа и монтажа:

**Демонтаж:**
- `floor_laminate` → `demo_floor_laminate`
- `wall_paint` → `demo_wall_paint`
- `ceiling_stretch` → `demo_ceiling_stretch`

**Монтаж:**
- `floor_laminate` → `install_floor_laminate`
- `wall_paint` → `install_wall_paint`
- `ceiling_stretch` → `install_ceiling_stretch`

**Черновые работы:**
- `floor_level_self` → `rough_floor_level_self`

**Чистовые работы:**
- `floor_level_self` → `finish_floor_level_self`

### Вариант 2: Использовать составные ID

Использовать полный путь в ID:
- `demolition_floor_laminate`
- `installation_floor_laminate`
- `rough_floor_level_self`
- `finishing_floor_level_self`

### Вариант 3: Реструктуризация лестниц

Для лестниц убрать дублирование между `by_material` и другими категориями:
- Оставить ID только в одном месте (например, в `by_material`)
- В других категориях использовать ссылки на базовые ID
