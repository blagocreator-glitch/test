## 🚀 Запуск за 5 минут

### 1. Клонировать репозиторий
```bash
cd "d:\Дмитрий работа\Ваши мастера\Разработка сайта\Сайт для работы"
```

### 2. Настроить окружение
```bash
# Скопировать пример конфигурации
copy .env.example .env

# Отредактировать .env (добавить SMTP-настройки)
notepad .env
```

### 3. Запустить локальный сервер
```bash
# Windows
serve.bat

# Или вручную
php -S localhost:8000
```

### 4. Открыть в браузере
```
http://localhost:8000/index.html
```

## 🎯 Основные концепции

### 1. Эталонный прайс-лист
**Все работы определены только в `prices_list.json`**

```javascript
// ✅ Правильно
const price = getWorkPrice('floor_laminate');

// ❌ Неправильно
const price = 500; // хардкод
```

### 2. Порядок скриптов критичен
Скрипты подключаются в строгом порядке (см. ARCHITECTURE.md)

### 3. Глобальное состояние
Все модули работают через глобальные переменные:
- `roomData` - данные помещений
- `pricesData` - прайс-лист
- `selectedItems` - выбранные позиции

## 🔧 Частые задачи

### Добавить новую работу
1. Открыть `prices_list.json`
2. Найти нужную категорию
3. Добавить работу:
```json
{
  "id": "new_work_id",
  "name": "Название работы",
  "unit": "м²",
  "prices": {
    "moscow": { "economy": 500, "standard": 700, "premium": 1000 }
  }
}
```
4. Перезагрузить страницу
5. Проверить консоль на ошибки

### Изменить цену
1. Открыть `prices_list.json`
2. Найти работу по `id`
3. Изменить цену в нужном городе/сегменте
4. Сохранить файл
5. Перезагрузить страницу

### Добавить новый город
1. Открыть `prices_list.json`
2. Добавить город в `countries`
3. Добавить цены для всех работ
4. Обновить UI для выбора города

### Отладить проблему
1. Открыть DevTools (F12)
2. Проверить Console на ошибки
3. Проверить Network на загрузку файлов
4. Проверить валидацию workId в консоли

## 🐛 Решение проблем

### Проблема: Не загружается прайс-лист
**Симптомы:** Ошибка в консоли "Failed to load prices_list.json"

**Решение:**
1. Проверить, что файл существует
2. Проверить валидность JSON: `python validate_json.py`
3. Проверить путь в `calc-init.js`
4. Очистить кеш браузера

### Проблема: Не работает калькулятор
**Симптомы:** Кнопки не реагируют, нет расчётов

**Решение:**
1. Открыть консоль (F12)
2. Проверить ошибки JavaScript
3. Проверить порядок подключения скриптов
4. Проверить, что `pricesData` загружен

### Проблема: Не отправляется почта
**Симптомы:** Форма отправляется, но письмо не приходит

**Решение:**
1. Проверить `.env` (SMTP-настройки)
2. Проверить `logs/mail_debug.log`
3. Проверить rate limiting
4. Проверить SMTP-сервер

### Проблема: Ошибки валидации workId
**Симптомы:** Предупреждения в консоли о несуществующих работах

**Решение:**
1. Найти workId в коде
2. Проверить, есть ли он в `prices_list.json`
3. Добавить работу в прайс-лист или исправить workId
4. Перезагрузить страницу
