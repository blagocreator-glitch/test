# Система Прайс-листа по Работам

## ⚠️ ВАЖНО: Эталонный источник данных

**Прайс-лист по работам является ЕДИНСТВЕННЫМ эталонным источником** для всех работ в системе калькулятора.

Это означает:
- ✅ Все названия работ берутся только из `prices_list.json`
- ✅ Все ID работ определяются только в `prices_list.json`
- ✅ Все единицы измерения (м², шт, пог.м) задаются только в `prices_list.json`
- ✅ Все базовые цены по городам и сегментам хранятся только в `prices_list.json`
- ❌ Нельзя создавать работы вне прайс-листа
- ❌ Нельзя дублировать определения работ в других файлах
- ❌ Нельзя переопределять названия или единицы измерения в коде

## Описание
Раздел "Прайс-лист по работам" позволяет управлять ценами на все виды ремонтных работ с автоматической интеграцией в итоговую смету.

## Расположение в сайте
- Раздел находится в калькуляторе ремонта после раздела "Что нужно сделать"
- Автоматически загружается вместе с основным содержимым

## Основные компоненты

### 1. Выбор города
- **Автозаполнение**: При заполнении поля "Местоположение объекта" город автоматически определяется
- **Ручной выбор**: Доступны города:
  - Москва
  - Московская область
  - Санкт-Петербург
  - Екатеринбург
  - Краснодар

### 2. Выбор типа рынка
Четыре варианта с различными ценовыми уровнями:
- **Бюджет/Аренда** - минимальный уровень цен
- **Комфорт** - средний уровень цен
- **Бизнес** - повышенный уровень цен
- **Премиум** - максимальный уровень цен

### 3. Опция корректировки цены вручную
- **Галка "Возможность корректировки цены вручную"** включает режим редактирования
- При включении появляются поля для ввода цены для каждой работы
- Кнопка "Сброс" позволяет восстановить исходную цену из базы

### 4. Список работ по категориям
Автоматически загружаются две основные группы:

#### Демонтажные работы
- Демонтаж пола (10 видов работ)
- Демонтаж стен (16 видов работ)
- Демонтаж потолка (9 видов работ)
- Демонтаж электрики (10 видов работ)
- Демонтаж систем водоснабжения (21 вид работ)
- Демонтаж канализации (10 видов работ)
- Демонтаж сантехники (12 видов работ)
- Демонтаж вентиляции (7 видов работ)

#### Монтажные работы по ремонту
- Электротехнические работы
- Сантехнические работы
- Работы со стенами
- Работы по полу
- Работы с потолком
- Работы по окнам и дверям

## Структура файлов

### prices_list.json
Основной файл с данными о работах и ценах:
```json
{
  "meta": { версия и информация },
  "countries": { информация о странах },
  "markets": { типы рынков },
  "works": {
    "demolition": { демонтажные работы },
    "installation": { монтажные работы }
  },
  "prices": {
    "Москва": {
      "Бюджет/Аренда": { цены },
      "Комфорт": { цены },
      "Бизнес": { цены },
      "Премиум": { цены }
    },
    ...
  }
}
```

### prices_list.js
JavaScript модуль с функциями:
- `initPriceList()` - инициализация системы
- `initializeLocationFromAddress()` - автозаполнение города из адреса
- `changePriceListCity(city)` - смена города
- `changePriceListMarket(market)` - смена типа рынка
- `togglePriceEditing(enabled)` - включение редактирования
- `getWorkPrice(workId)` - получить цену работы с учетом перезаписей
- `updatePriceOverride(itemId, value)` - обновить цену вручную
- `resetPriceOverride(itemId)` - сбросить цену к исходной

## Интеграция с калькулятором

### Автоматическое обновление сметы
- При изменении города или типа рынка цены автоматически обновляются
- При ручной корректировке цены немедленно учитываются в итоговой смете
- Скорректированные цены сохраняются и используются для всех расчетов

### Валюта
- Во всех городах используется русский рубль (₽)
- Обмен валют можно добавить в будущих версиях

## Добавление новых городов

Для добавления нового города необходимо:

1. **Обновить prices_list.json:**
```json
"NewCity": {
  "name": "Название города"
}
```

2. **Добавить цены для новых рынков:**
```json
"NewCity": {
  "Бюджет/Аренда": { все 80+ работ с ценами },
  "Комфорт": { все 80+ работ с ценами },
  "Бизнес": { все 80+ работ с ценами },
  "Премиум": { все 80+ работ с ценами }
}
```

3. **Структура цены:** `"работа_id": число`

## Пример использования

1. Пользователь заполняет "Местоположение объекта": "Санкт-Петербург, ул. Невского, 10"
2. Система автоматически выбирает "Санкт-Петербург" в прайс-листе
3. Пользователь выбирает тип рынка "Комфорт"
4. Система загружает все цены для Санкт-Петербурга и рынка Комфорт
5. Пользователь видит все работы с ценами
6. Если нужна корректировка - включает галку "Возможность корректировки цены вручную"
7. Изменяет цены для нужных работ
8. Скорректированные цены автоматически используются в расчетах

## Важные замечания

### Сохранение цен
⚠️ В текущей версии скорректированные цены сохраняются в памяти браузера только во время сессии.
Для постоянного сохранения нужно добавить localStorage.

### Производительность
- При большом количестве работ (200+) рекомендуется использовать пагинацию
- Фильтрация по категориям поможет улучшить интерфейс

### Безопасность
- Все цены являются справочными
- Финальная сметапроверяется на стороне сервера перед отправкой
